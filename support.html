Support

Answers to common questions about OpenChat for iPhone and iPad.

How do I add an AI provider?

Open Settings → Service Providers, tap add, choose a preset or enter any OpenAI-compatible base URL, paste your API key, and save. Your key is stored in the device Keychain and sent only to that provider.

How do I run Hermes Agent from OpenChat?

Hermes is included with OpenChat Pro. OpenChat turns Hermes into a local OpenAI-compatible backend. Open Settings → Service Providers, tap Hermes, then follow the in-app setup card: copy the generated start command, paste it into Terminal on the Mac running Hermes, and keep the gateway running. On a real iPhone, replace 127.0.0.1 with your Mac's local network address and allow local-network access if iOS asks.

Already running Hermes in Docker? Use “Copy Existing Key Command” in the setup card to read the current API key, then paste that key when prompted.

Where do I get an API key?

Create an account with a provider such as OpenAI, Anthropic, Google, or DeepSeek, then generate an API key on their developer platform. You pay the provider directly for usage.

Messages aren't sending

  • Check that your API key is valid and has credit on the provider's dashboard.
  • For Hermes, confirm the gateway is running and use your Mac's local network address on iPhone.
  • Verify the base URL matches your provider exactly.
  • Try switching to another model from the header menu.

How does iCloud backup work?

If enabled, OpenChat saves a copy of your conversations to your private iCloud Drive. Your data stays in your own iCloud account — we have no access to it.

Restoring a purchase

OpenChat Pro is tied to your Apple ID. Reinstalling or switching devices? Open Settings and choose Restore Purchase.
